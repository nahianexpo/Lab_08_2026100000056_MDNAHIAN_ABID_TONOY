### 1. What is Version Control?
Version Control is like an Undo button for whole project.It saves old versions of your work so you can easily go back if you make a mistake.

### 2. What is Git?
Git is a smart notebook on a computer that keeps track of every single change we can make to our files.

### 3. What is GitHub?
GitHub is a magic cloud folder on the internet where we save our Git notebook so our instructor and friends can see and work together on it.

### 4. What is Git Bash?
Git Bash is a special typing box (terminal) on Windows where we can give simple text commands to Git.

### 5. What are the Main Parts of GitHub?
1.**Repository:** Your main project bag where all files and history live.

2.**Commit:** Taking a quick photo (snapshot) of your work to save it.

3.**Branch:** A secret practice paper to try new ideas without spoiling the main work.

4.**Pull Request:** Asking your team, "Can I add my practice work to the main project?" 

5.**Issues:** A sticky note list of bugs to fix or tasks to complete.
